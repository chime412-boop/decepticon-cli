# Phase 3 — structured handoff

Acceptance criteria:
1. Handoff is structured, not only narrative.
2. It records objective, status, next action, blockers and ruled-out paths.
3. It can carry files, commands, results, errors and evidence.
4. Latest handoff can be retrieved by project/machine.
5. context_bundle returns bounded pending work, sessions, latest handoff and recent events.
6. Handoff updates task next_action/blocked_on.
7. All Phase 1 and Phase 2 tests remain green.
